# Проверка лобового Waze HUD в BYD Sea Lion 07

Документ относится только к проекции на лобовом стекле. Лаборатория приборной панели за рулём,
её сценарии, тестовые поверхности и служебные команды удалены из BYDMate Dev.

## Условия

- Автомобиль стоит на месте, селектор в `P`, скорость равна 0.
- Используется Waze (`com.waze`).
- Рабочий путь Waze Accessibility → SOME/IP HUD сохраняется.
- Проверка по этой инструкции необязательна и сама по себе не запускает тест или установку APK.

## Лобовой HUD

В `Центре диагностики` остаётся отдельная лаборатория лобового HUD. Для ручной проверки доступны
существующие подтверждённые сценарии `SL01–SL05`; условия парковки и автоматическая очистка
сохраняются. Исторические `HX01–HX05` не возвращены в доступный каталог.

При проверке обычного маршрута Waze оценивайте правильность стрелки, обновление расстояния и
названия улицы, отсутствие прежнего мигания. Успешная отправка Binder/SOME-IP сама по себе не
подтверждает видимое изображение.

## Завершённые пробы дополнительных символов

Explorer и «Доп. навигация» удалены из запуска. В журнале 08.09.2026 все четыре кандидата
`E31/E2D/E2E/E30` показали только «прямо». Круг для `R01/R02` тоже не подтвердился, а `U01/U02`
показали разворот. Повторять Explorer в этой сборке нельзя; старые результаты сохраняются.

Разбор ограничений каталога и новая информация из схемы прошивки приведены в
[отчёте по индикаторам HUD](sea-lion-07-hud-indicator-findings.md).

## Экспорт

Кнопка экспорта в лаборатории лобового HUD сохраняет только её результаты. Раздела тестов
приборной панели в новых экспортируемых файлах больше нет. Ранее сохранённые внешние архивы
и материалы диагностики камер не изменяются.
